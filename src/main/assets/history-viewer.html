Linux Sensor Tray — history viewer

Drag and drop linux-sensor-tray-*.jsonl (or legacy monitor-*.jsonl) files. Everything runs locally in this file — nothing is uploaded. Charts support wheel zoom and drag-pan (the toolbar keeps all charts in sync), and periods where the machine was off or logging was paused are drawn as gaps instead of straight lines.

Drop .jsonl history files here
Compact fields power the first charts; extended blocks (mem, cpu, …) add more charts and the detail panel.

  1. Logs live next to this file, one per day, named linux-sensor-tray-YYYY-MM-DD.jsonl: the folder this history-viewer.html was opened from
  2. Folder empty apart from this page? Disk logging is off — turn on Settings → Disk logging → “Log samples to disk” in Linux Sensor Tray. The first line is written one write-interval later, so a brand-new log can legitimately hold zero samples.
  3. A day with the machine powered off simply has no file; a day it was on and off has one file with gaps. You can drop several days at once — they are merged and sorted by timestamp.
